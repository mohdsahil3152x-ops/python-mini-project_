# Python Mini Projects

This repository contains beginner-level Python mini projects created while learning Python programming and improving problem-solving skills.

## Projects Included

1. Calculator
   - Performs basic arithmetic operations
   - Uses conditions and exception handling

2. Number Guessing Game
   - User guesses a randomly generated number
   - Uses loops, conditions, and random module

3. ATM Simulation
   - Check balance
   - Deposit money
   - Withdraw money
   - Uses loops and conditional statements

## Concepts Used

- Variables
- Loops
- Conditional Statements
- Exception Handling
- Functions
- Random Module

## Goal

The purpose of these projects is to improve Python logic building and coding implementation skills.
